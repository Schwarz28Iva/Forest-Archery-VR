# Third-party content

The complete private Unity project uses external visual, audio, animation, and 3D assets in addition to Unity and Meta XR packages.

Those raw third-party assets are intentionally **not redistributed** in this public portfolio repository.

The screenshots in `docs/assets/` show the assembled application as it appeared during development and evaluation. The public `src/` directory contains only a curated selection of project-authored C# files aligned with Valentina Indrei's documented contribution areas.

Notable external content used in the full project included environment, vegetation, animal, weapon, audio, and animation assets. The Living Birds asset supplied bird movement/animation behaviour; project code integrated bird hits with the scoring/game systems.
