# Project environment

The full private Unity project was developed with:

- **Unity:** 6000.3.6f1
- **Meta XR SDK Core:** 201.0.0
- **Meta XR Interaction SDK:** 201.0.0
- **XR Interaction Toolkit:** 3.3.1
- **OpenXR:** 1.16.1
- **Unity AI Navigation:** 2.0.9
- **Universal Render Pipeline:** 17.3.0
- **Target hardware:** Meta Quest 3

This public repository is **not a standalone Unity build**. It contains selected project-authored C# source files and documentation intended for portfolio review. The complete development project remains private because it includes third-party Unity assets and package content that are not redistributed here.
