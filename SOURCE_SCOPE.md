# Public source scope

This repository is a **curated portfolio version**, not the complete Unity project.

The selected C# files correspond to areas documented as Valentina Indrei's contributions in the final project report:

- scoring configuration and score feedback;
- wildlife-hit integration;
- HUD and menu flow;
- local player profiles and leaderboards;
- experiment/logging infrastructure.

The original team project also contains controller/hand-tracking bow interaction, arrow mechanics, XR setup, Android/Quest integration, editor utilities, scenes, package samples, and third-party assets. Those parts are intentionally not republished here.

Because this is only a selected source subset, the files in `src/` are provided for code review and are **not expected to compile as a standalone Unity project**.
